# IRR Advisor

Мини-экспертная система сравнения 2–3 инвестиционных проектов.

### Тесты

```bash
python -m unittest discover -s tests -v
```

### Модель

Ввод: начальная инвестиция `I0 > 0`, затем 5–8 годовых потоков. Допускаются отрицательные потоки в начале проекта, **но после первого положительного потока отрицательные запрещены** — это обеспечивает единственность IRR. IRR находится бисекцией как корень `NPV(r) = -I0 + sum(CFt/(1+r)^t) = 0`. Если положительных потоков нет, IRR не существует. Ставка дисконтирования используется для NPV и проверки приемлемости. Для взаимоисключающих проектов приоритет имеет максимальный NPV.
